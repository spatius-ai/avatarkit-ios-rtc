# Archived Docs — iOS RTC SDK

Documents written before the current `docs/` structure was adopted, kept as-is.

## What this directory is for

These files predate the [`architecture/`](../architecture/) /
[`decisions/`](../decisions/) split and do not fit either layer:

- They are **not** guaranteed to describe current behavior — do not cite them as
  current state. The authoritative current state is
  [`../architecture/`](../architecture/), which is re-verified against code on
  every release.
- They are **not** dated iteration entries either, so they do not belong in
  [`../decisions/`](../decisions/).

They are kept because they still carry useful background. Read them as history.

## Rules

- **Frozen.** Nothing new is added here. Any new document goes to
  `architecture/` (current state) or `decisions/` (a recorded decision).
- Not covered by the release-time docs alignment gate
  (→ `knowledge/workflows/release-workflow.md` §1.1).
- If a file here turns out to still describe current behavior, promote its
  content into the matching `architecture/` file rather than citing it from here.
