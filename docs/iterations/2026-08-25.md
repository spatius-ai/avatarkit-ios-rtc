## 2026-08-25T21:16:02+08:00 — Adopt the unified SDK docs structure

**Scope:** Roll out the three-layer `docs/` structure (`architecture/` +
`iterations/` + `history/`) defined in `knowledge/docs-structure-spec.md`, and put
this repo under the commit-time and release-time documentation rules. The same
change landed across all seven SDK repos in the same pass, with an **identical**
directory layout and identical `architecture/` filenames in every repo.

### What changed

- Created the three layers: `docs/architecture/` (current state, rewritten in
  place), `docs/iterations/` (append-only history), `docs/history/` (frozen
  archive of docs predating this structure).
- `architecture/` now holds exactly the five mandatory files, same names as the
  other six repos: `docs-map.md`, `overview.md`, `release-process.md`,
  `telemetry-fields.md`, `test-cases.md`.
- Migrated pre-existing docs:
  - None — this repo had no `docs/` directory before this change.
- Added `docs/README.md`, `docs/architecture/docs-map.md`,
  `docs/iterations/README.md`, `docs/iterations/_TEMPLATE.md`,
  `docs/history/README.md`.
- Created skeletons for the mandatory `architecture/` files this repo was missing:
  - `architecture/overview.md` — **skeleton, not yet verified against code**
  - `architecture/release-process.md` — **skeleton, not yet verified against code**
  - `architecture/telemetry-fields.md` — **skeleton, not yet verified against code**
  - `architecture/test-cases.md` — **skeleton, not yet verified against code**
- Updated path references in this repo's `CLAUDE.md` / `README.md` /
  `CHANGELOG.md` where they pointed at the old flat layout.

### Problems hit

- First pass left the seven repos **structurally inconsistent**: platform-specific
  leftovers (`api-reference-internal.md`, `sdk-stability-priorities.md`,
  `performance/`, the Agora/LiveKit integration notes) had been placed under
  `architecture/`, so the directory held 5–7 differently-named files depending on
  the repo. Resolved by introducing the `history/` layer and moving everything
  that does not map onto one of the five mandatory files into it — `architecture/`
  is now byte-for-byte identical in filenames across all seven repos.
- Docs that moved one directory deeper had stale relative links
  (`../../sdk-release-manager/README.md`, `../CHANGELOG.md`). Found by a link
  check over all `docs/**/*.md` and corrected.

### Bugs fixed

- None — documentation-only change, no code touched.

### Architecture docs touched

- `architecture/docs-map.md` — created, lists every file now under `docs/`.
- Skeleton files listed above were created but **not** filled; they carry a
  `STATUS: NOT YET FILLED` banner and must not be cited as current state until
  verified against code.
